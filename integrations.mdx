## Version Control Sync

Connect TWG to GitHub for automatic syncing of your documentation. Push changes to your repo, and TWG pulls updates in real-time.

<Steps>
  <Step title="Create Repository" icon="repo" title-type="p">
    Set up a new GitHub repository for your docs.
  </Step>

  <Step title="Connect TWG" icon="link" title-type="p">
    In TWG settings, enter your repo URL: `https://github.com/your-org/your-docs`.
  </Step>

  <Step title="Configure Webhook" icon="settings" title-type="p">
    Add a GitHub webhook pointing to your TWG sync endpoint.
  </Step>

  <Step title="Sync Changes" icon="git-commit" title-type="p">
    Push commits to trigger automatic updates.
  </Step>
</Steps>

<Callout kind="tip" collapsed="false">
  Enable branch protection in GitHub to ensure only approved changes sync to TWG.
</Callout>

## Export Options

Export your TWG documentation to PDF or Markdown for sharing or archiving.

<Tabs>
  <Tab title="PDF" icon="file-text">
    Use the export API to generate PDFs.

    <CodeGroup show-lines="true">
      ```bash
      curl -X POST https://api.example.com/v1/docs/export/pdf \
        -H "Authorization: Bearer YOUR_API_KEY" \
        -d '{"docId": "your-doc-id"}'
      ```

      ```javascript
      const response = await fetch('https://api.example.com/v1/docs/export/pdf', {
        method: 'POST',
        headers: {
          'Authorization': 'Bearer YOUR_API_KEY',
          'Content-Type': 'application/json'
        },
        body: JSON.stringify({ docId: 'your-doc-id' })
      });
      const pdfUrl = await response.json();
      ```
    </CodeGroup>
  </Tab>

  <Tab title="Markdown" icon="markdown">
    Export as clean Markdown files.

    <CodeGroup show-lines="true">
      ```bash
      curl -X POST https://api.example.com/v1/docs/export/md \
        -H "Authorization: Bearer YOUR_API_KEY"
      ```

      ```python
      import requests
      response = requests.post(
          'https://api.example.com/v1/docs/export/md',
          headers={'Authorization': 'Bearer YOUR_API_KEY'}
      )
      markdown = response.text
      ```
    </CodeGroup>
  </Tab>
</Tabs>

## Embedding TWG Pages

Embed interactive TWG documentation in your website using an iframe.

```html
<iframe
  src="https://docs.example.com/embed/your-doc-id"
  width="100%"
  height="600"
  frameborder="0">
</iframe>
```

Customize with query params like `?theme=dark&readOnly=true`.

## Webhooks for Updates

Set up webhooks to notify external services when your docs change.

<Request show-lines="true">
  ```javascript
  // Payload sent to your webhook URL
  await fetch('https://your-webhook-url.com/twgdocs', {
    method: 'POST',
    body: JSON.stringify({
      event: 'doc.updated',
      docId: 'abc123',
      version: '1.2.3',
      timestamp: '2024-01-15T10:30:00Z'
    })
  });
  ```
</Request>

<Response show-lines="true">
  ```json
  {
    "status": "received",
    "event": "doc.updated"
  }
  ```

  ```json
  {
    "error": "Invalid signature"
  }
  ```
</Response>

<ParamField header="X-TWG-Signature" param-type="string" required="true" deprecated="false" show-location="true">
  HMAC SHA-256 signature of the payload using your webhook secret.
</ParamField>

## Third-party Auth Providers

Integrate OAuth providers for user authentication.

<Expandable title="Google OAuth Setup" default-open="true">
  1. Register your app in Google Cloud Console.
  2. Add client ID and secret to TWG settings.
  3. Redirect users to `https://api.example.com/auth/google`.
</Expandable>

<Expandable title="GitHub OAuth" default-open="false">
  Configure scopes: `user:email, repo`.
</Expandable>
