## Prerequisites

Before starting, ensure you have:

- A modern web browser (Chrome, Firefox, Safari, or Edge)
- An email address for account verification
- Optional: A GitHub account for version control integration

<Callout kind="info" collapsed="false">
  No credit card or payment required for the free tier. Upgrade later for advanced features.
</Callout>

## Create Your Account

Follow these steps to sign up and access your TWG dashboard.

<Steps>
  <Step title="Visit TWG" icon="globe" title-type="p">
    Navigate to `https://app.twg.com` and click **Sign Up**.
  </Step>

  <Step title="Enter Details" icon="user" title-type="p">
    Provide your email, create a password, and accept the terms.
  </Step>

  <Step title="Verify Email" icon="mail" title-type="p">
    Check your inbox for the verification link and click it to activate your account.
  </Step>

  <Step title="Access Dashboard" icon="dashboard" title-type="p">
    Log in to reach your personal dashboard.
  </Step>
</Steps>

## Set Up Your First Documentation Space

Once logged in, create a space for your project docs.

<Steps>
  <Step title="Create Space" icon="plus" title-type="p">
    Click **New Space** and name it (e.g., "My Project Docs").
  </Step>

  <Step title="Configure Basics" icon="settings" title-type="p">
    Add a description like "Documentation for TWG travel projects" and set visibility to public or private.
  </Step>

  <Step title="Add Navigation" icon="menu" title-type="p">
    Create pages: Home, Quickstart, API.
  </Step>
</Steps>

## Add and Organize Documents

Populate your space with content.

<Tabs>
  <Tab title="Markdown Editor" icon="edit-3">
    Use the built-in editor.

    ```markdown
    # Welcome to TWG Docs

    ## Overview

    Reisen in guter Gesellschaft – bester Preis-/Leistung.

    - Busreisen
    - Flug & Bus
    - Musikreisen
    ```

    Preview changes in real-time.
  </Tab>

  <Tab title="Import from GitHub" icon="github">
    Connect your repo.

    <CodeGroup show-lines="true">
      ```bash
      twg import --repo owner/my-docs --space "My Project Docs"
      ```

      ```bash
      # Or via GitHub app
      npx twg-github-app install
      ```
    </CodeGroup>
  </Tab>
</Tabs>

## Preview and Publish

Test and go live.

<Steps>
  <Step title="Preview" icon="eye" title-type="p">
    Click **Preview** to see your site as visitors will.
  </Step>

  <Step title="Publish" icon="upload-cloud" title-type="p">
    Hit **Publish** to deploy. Share the URL: `https://docs.twg.com/your-space`.
  </Step>
</Steps>

<Callout kind="tip" collapsed="false">
  Changes auto-save. Use version history for rollbacks.
</Callout>
