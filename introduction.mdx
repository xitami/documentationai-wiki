## Welcome to TWG

TWG's travel technology platform connects data synchronization, operational analytics, document generation, and guest feedback analysis into an integrated workflow for travel operations. Four product areas work together:

- **TourData Mirror:** Synchronizes trip, booking, and disposition data from upstream systems, exposing it through aggregate APIs and MCP tools for reporting and integration.
- **KD Dossier:** Generates travel documents and PDF exports from mirrored data, ensuring the exported document matches what editors see in the application.
- **Review Analytics:** Analyzes questionnaire results and guest feedback across trips, with year-over-year comparisons, top/flop rankings, and AI-assisted report generation.
- **Fullstack Starter:** Provides shared authentication, navigation, entity notes, and a versioned API that all TWG applications build on.
